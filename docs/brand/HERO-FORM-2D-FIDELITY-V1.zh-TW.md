# 大尺寸 Logo 精修 — 高保真 2D 形體 V1

**狀態：候選預覽，未獲使用者正式驗收。不是 3D 建模，也不應取代原始母版。**

## 為什麼重做
首頁原先直接把 384×384 的點陣 Logo 放大到接近 985px；清晰化或普通自動向量描圖雖然讓邊緣變硬，卻經常改變了原本的交疊結構，尤其三處白色弧形空隙。

**目標：提升放大後的平滑度，同時保留原圖的外輪廓、中心負空間和三處物理上有意義的前後交疊邊界。**

## 源文件和重建流程
- 原始幾何圖：Kairo 上已保留的 `logo-geometry-corrected-construction-notes.original.jpeg`，本次**未修改**。
- 建置輸入：`baicai-brand-kit/reference/identity-2026-11-10/source/approved-motherform-crop-401x438.png`。
  - 從原始設計板像素精確裁出 `(54,231)-(455,669)`；不是新畫的替代母版。
- 可重現建置腳本：`scripts/reconstruct-hero-logo.py`（build-time Python，需 `numpy`、`scipy`、`opencv-python-headless`、`Pillow`）。
- 畫面專用資產：
  - `public/brand/identity-2026/hero-solid-form-structural-mono-v1.svg` — **首頁目前候選版**，使用原本低調背景視覺。
  - `public/brand/identity-2026/hero-solid-form-structural-satin-v1.svg` — 同一組幾何的暖灰棕材質草圖，不在首頁啟用。

## 幾何重建方法
1. 從原圖裁圖取出暗色母形。
2. 以有限度形態學閉合**辨識**黑色環帶的外輪廓、內部三角負空間，以及精細的三處缺口。
3. 將外輪廓、內部空間和三個不同的缺口，分成 **5 個各自獨立的封閉路徑**。
4. 每個路徑按原始像素曲線擬合週期三次樣條，保持光滑與低誤差。
5. 在 SVG 使用 `fill-rule="evenodd"`。三處前後交疊的界面是**真實透明的負空間區域**，不是在三角環上另畫的白色描邊。
6. 不改捲動動畫與頁面佈局，只替換主頁背景大圖來源。

## 有限度的客觀驗證
將 SVG 縮到母版裁圖原生的 401×438px，以固定灰階閾值比較像素佔據區：
- 已確認輪廓 Mask IoU 約 **0.98**（約 98%），**不是** 3D 形體正確率，也不是設計師驗收通過率。
- 原始母版有印刷／抗鋸齒和微細陰影；這是光學精修而非數學意義上的唯一精確建構。

## 邊界
- **不是 3D 模型**：3D 的曲面法線、可見厚度、物理可實現性仍未確定。
- **不是把白線當裝飾**：三個 gap 各自從原稿擷取，彼此與環帶輪廓同等重要。
- **不是替換 Logo 母版**：小尺寸 Header、favicon、PWA 一律沿用原檔。
- 使用者驗收前不合併主站 `main`，也不把此實驗變成全站替換。

## 人工驗收
先檢查**原稿與大尺寸向量圖並排**：
- 圓角外輪廓與內側空間的張力是否一致？
- 三處分界線的起點、終點、弧度與留白是否符合原本的前後交疊意義？
- 放大到約 1000px 時是否出現突角、破線、變形？
- 回到小尺寸時是否維持原有的辨識性？

確認幾何以後，才討論材質及更有層次的光影。
