# baicai.dev 品牌使用說明

## 1. 品牌概念

### A1：白菜守望者

A1 不是 Mark 的寫實肖像，而是他的「精神徽章」。

- 正面對稱：秩序、穩定、專注。
- 兜帽：保留私人空間，也象徵進入未知世界的探索者。
- 白菜葉片面罩：名字 `baicai`、生命、生長、普通事物的重新創造。
- 綠色觀察鏡：科技、AI、資料與持續觀察。
- 圓形資料環：不同生活領域被逐步連接成一個系統。
- 胸前 Future B：角色與網站品牌屬於同一套世界觀。

A1 應呈現「神祕但不陰暗、強大但不具攻擊性」。禁止增加武器、軍事裝備、骷髏、獠牙或過度電競化的元素。

### Future B：正式 Logo

Future B 同時包含：

- `B`：baicai 的首字母；
- 葉片：成長、生命、希望；
- 電路節點：程式、工具、自動化；
- 資料流：把工作、生活、信仰、學習與科技連接起來。

## 2. 使用層級

| 場景 | 使用素材 | 建議尺寸 |
|---|---|---|
| 網站導航列 | `logo-mark-primary.svg` + 即時文字 | 28–36px |
| 手機窄版導航 | `logo-mark-primary.svg` | 28–32px |
| favicon | `favicon.svg` / `.ico` | 16–48px |
| GitHub／社交頭像 | Future B 或 A1 avatar | 256px 以上 |
| 首頁 Hero | A1 1024 WebP | 260–480px |
| About 頁 | A1 1024 PNG/WebP | 320–560px |
| 404／空狀態 | A1 | 180–360px |
| 工具卡片圖標 | Future B 的簡化版 | 24–48px |

## 3. 安全留白

Future B 四周至少保留「一個節點直徑」的空間。不要貼住容器邊緣。

A1 不要裁掉兜帽頂端、面罩下端或胸前 B。可裁切肩部，但必須保持中心對稱。

## 4. 顏色

- 背景：`#071015`
- 表面：`#0E1D22`
- 主綠：`#72D06B`
- 柔光綠：`#B8F58B`
- 科技青：`#35B7A6`
- 暖米色：`#E8DFC8`
- 主文字：`#F5F7F2`
- 次文字：`#95A29B`

發光效果應局部使用。大部分介面保持沉穩深色，讓 Logo、互動狀態與重要資訊才出現綠光。

## 5. 禁止事項

- 不要把 A1 縮到 favicon。
- 不要拉伸或改變比例。
- 不要加粗到堵塞葉片負空間。
- 不要在複雜照片上直接放彩色 Logo；請使用單色版或加底板。
- 不要同時大量使用綠色漸層、光暈、粒子、掃描線。
- 不要讓視覺變成遊戲戰隊、加密貨幣或資安公司的既視感。
