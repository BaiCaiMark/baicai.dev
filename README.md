# baicai.dev

A practical personal site for useful tools, projects, notes, and contact information.

## Structure

- `/` - homepage
- `/about` - short personal introduction
- `/projects` - project list
- `/tools` - tool directory
- `/tools/a5-bridge-saw` - A5 bridge saw converter
- `/tools/scripture` - client-side scripture helper
- `/notes` - lightweight notes
- `/contact` - contact details

## Stack

- Next.js 16
- React 19
- Tailwind CSS 4
- Vercel

## Local development

```bash
npm install
npm run dev
```

Then open `http://localhost:3000`.
